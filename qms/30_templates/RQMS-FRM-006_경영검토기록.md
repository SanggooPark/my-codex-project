# RQMS-FRM-006 경영검토 의제 및 기록

근거 조항: ISO 22163:2023 9.3.1.1, 9.3.2, 9.3.2.1, 9.3.3, 9.3.3.1 / 시스템 테이블: `management_review`

| 항목 | 기재 내용 |
| --- | --- |
| 기록 번호 | MR-YYYY-NN |
| 구분 | 연간(annual) / 추가(extraordinary) |
| 추가 검토 사유 | 중대 품질사고 또는 RQMS 중대 변경 (추가 검토 시 필수) |
| 실시일 / 참석자 | |

## 입력 — ISO 9001:2015 9.3.2

| 항목 | 내용 |
| --- | --- |
| a) 이전 경영검토 조치 상태 | |
| b) 내·외부 이슈 변화 | |
| c) 1) 고객만족 및 이해관계자 피드백 추세 | |
| c) 2) 품질목표 달성도 | |
| c) 3) 프로세스 성과 및 제품·서비스 적합성 | |
| c) 4) 부적합 및 시정조치 | |
| c) 5) 모니터링·측정 결과 | |
| c) 6) 심사 결과 | |
| c) 7) 외부공급자 성과 | |
| d) 자원의 충족성 | |
| e) 리스크·기회 조치의 효과성 | |
| f) 개선 기회 | |

## 입력 — ISO 22163:2023 9.3.2.1 (철도 부문 추가)

| 항목 | 내용 |
| --- | --- |
| a) 프로젝트 검토의 핵심 이슈 | |
| b) 프로세스 검토 결과(선별) | |
| c) 전 KPI 및 PI 분석 결과 | |
| d) 실제·잠재 내·외부 실패와 그 안전 영향 | |
| e) 사업계획 출력 | |

## 출력 — 9.3.3 및 9.3.3.1

| 항목 | 결정 및 조치 |
| --- | --- |
| a) 개선 기회 | |
| b) RQMS 변경 필요성 | |
| c) 자원 소요 | |
| 9.3.3.1 a) 목표 달성(품질·안전 목표 최소 포함) | |
| 9.3.3.1 b) 고객만족 | |

목표가 달성되지 않은 경우 10.2 에 따라 시정조치를 관리한다. 시스템은 미달 목표에
시정조치가 연계되지 않은 상태의 경영검토 기록을 거부한다(CTL-020).

## 입력 초안 생성

```bash
python -m rqms conformity          # 조항 적합성
python -m rqms check               # 통제 위반
python -m rqms indicators          # KPI/PI 실적
python -m rqms report --out mr.html
```
