# QMS 문서화된 정보 체계

ISO 22163:2023 7.5.3.3 b)~d) 는 문서화된 정보의 계층, 작성·검증·승인·갱신 권한,
기록 유형과 보존기간을 정하도록 요구한다. 이 디렉터리가 그 문서 체계이다.

| 2 | `20_processes/` | 프로세스 기술서 (29건) | 대표이사 |

## 3. 작성·검증·승인 권한 (7.5.3.3 c)

시스템은 다음을 강제한다(CTL-001).

1. 문서는 `draft` → `in_review` → `approved` 순서로만 전이한다.
2. 검토자 지정 없이 승인할 수 없다.
3. **작성자는 승인자가 될 수 없다.**
4. 승인되지 않은 문서는 생산 착수, 출하, 검사, 계획 등록 등 어떤 업무에도 사용할 수 없다.

승인 시점에 문서 내용의 SHA-256 봉인을 생성하며, 내용이 사후에 바뀌면 봉인 불일치로
탐지된다(CTL-002, 7.5.3.2 "의도하지 않은 변경으로부터 보호").

## 4. 기록 유형 및 보존기간 (7.5.3.3 d)

| 기록 유형 | 보존기간 | 근거 |
| --- | --- | --- |
| 품질매뉴얼·방침 | 폐지 후 10년 | 계약·규제 요구 |
| 프로세스 기술서 | 폐지 후 10년 | 7.5.3.3 |
| 경영검토 기록 | 10년 | 9.3.1.1 |
| 내부심사 보고서 | 5년 (심사 주기 3년 + 여유) | 9.2.3.2 c) |
| 설계 출력·안전 케이스 | 제품 수명주기 + 10년 | 8.3.5, 8.8.3 |
| 형상 기준선·형상상태 기록 | 제품 수명주기 + 10년 | 8.1.4.1.1 |
| 추적성 기록 | 보증 종료 후 10년 이상 | 8.5.2.1 |
| 검사·시험 기록, FAI 기록 | 보증 종료 후 5년 | 8.6, 8.9 |
| 부적합·특채·시정조치 기록 | 10년 | 8.7.2, 10.2.2 |
| 교정·검증 기록 | 5년 | 7.1.5.3 |
| 역량·교육 기록 | 재직 종료 후 5년 | 7.2 |
| RAMS·현장 데이터 | 제품 수명주기 | 8.8.2 c) |

보존기간이 정의되지 않은 기록은 등록할 수 없고, 보존기간 만료 전 폐기는
거부된다(CTL-003).

## 5. 기밀등급 및 저장 (7.5.3.3 권고)

| 등급 | 적용 | 취급 |
| --- | --- | --- |
| public | 인증서, 방침 요약 | 외부 공개 가능 |
| internal | 매뉴얼, 프로세스 기술서, 서식 | 사내 전용 (기본값) |
| confidential | 사업계획, 원가, 고객 규격 | 접근 권한자 한정 |

전자 문서는 정보시스템으로 관리하고 백업 절차를 정의한다. 폐기는 전자 파일 완전 삭제 및
출력물 파쇄로 한다.

## 6. 외부 출처 문서 (7.5.3.2)

고객 규격, 적용 표준(ISO 22163, IEC 62278 등), 법규는 `doc_type = 'external'` 로
등록하여 식별·관리하며 개정 여부를 정기적으로 확인한다.
